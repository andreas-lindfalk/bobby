# Orihuelacosta.ai (Project Bobby)

A **Vertical AI Agent & Managed Marketplace** for Northern European expats on Costa Blanca, Spain.

## What is this?

A digital bridge between Spanish bureaucracy/service providers and expat homeowners. Think "Habeno for living" — automating cross-border tax compliance (Swedish ROT/RUT, German § 35a EStG, UK CGT) with escrow-backed service guarantees.
